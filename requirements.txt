# Required Libraries for Gesture-Controlled Robotic Arm Project
# Install them in the Arduino IDE via Sketch > Include Library > Manage Libraries,
# searching for the exact names below.

# Board support (Boards Manager): "esp32" by Espressif Systems
# Provides WiFi.h and Wire.h, so they are not installed separately.

# MQTT Client library
PubSubClient (by Nick O'Leary)

# MPU6050 library for motion sensors (used by src/Glove.ino)
MPU6050 (by Electronic Cats)

# PWM Servo Driver library
Adafruit PWM Servo Driver Library (by Adafruit)

# AccelStepper library for controlling stepper motors
AccelStepper (by Mike McCauley)

# Only needed for the sketches in tests/Embedded Systems
# (Library Manager will offer to install their dependencies, e.g. Adafruit BusIO)
Adafruit MPU6050 (by Adafruit)
Adafruit Unified Sensor (by Adafruit)
